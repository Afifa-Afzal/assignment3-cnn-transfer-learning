# Assignment 3: CNN, Transfer Learning, and Object Detection

Image classification on CIFAR-10 (small CNN vs ResNet18 transfer learning) and object detection with Faster R-CNN.

## Results

| Model | Trainable params | Train time | Test acc |
|---|---|---|---|
| Small CNN | 620,362 | 122.6 s (10 ep) | 76.74% |
| ResNet18 feature extraction | 5,130 | 97.9 s (5 ep) | 85.42% |
| ResNet18 fine-tuning | 11,181,642 | 318.2 s (5 ep) | 92.90% |

Faster R-CNN (ResNet50-FPN, COCO pretrained): 170.6 ms/image (~5.9 FPS) on a T4 GPU.

## Contents
- `Assignment3_CNN_TransferLearning.ipynb`: full code
- `Assignment3_Report.pdf`: report
- `outputs/`: plots, detection images, `results.json`

## How to run
Open the notebook in Google Colab, set Runtime to T4 GPU, and run all cells.
Python, PyTorch, torchvision. Seed = 42. Split: 45,000 train / 5,000 val / 10,000 test.
Model weights (`.pth`) are not included; they are regenerated by running the notebook.
